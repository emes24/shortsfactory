Privacy Policy

Last updated: 28 September 2026

1. Who this concerns

Shorts Factory is a private tool with a single user: its owner. It collects no data from anyone else, because no one else uses it.

2. What data is handled

The tool stores only what is needed to upload videos to its owner's own TikTok account:

  • An OAuth access token and refresh token issued by TikTok, kept in a local file on the owner's computer.
  • The video files and text scripts created by the owner.

3. Where data is stored

Everything stays on the owner's personal computer. No database, no server, no cloud storage, and no transmission to any third party. The only external connection is to TikTok's own API, to upload videos.

4. What is not collected

The tool collects no personal information from TikTok users, no analytics, no viewer data, no contact details, and no browsing activity. It does not read followers, comments, messages or profile data.

5. Data sharing

No data is sold, shared or disclosed to anyone. There are no advertisers, analytics providers or third-party integrations.

6. Retention and deletion

Tokens are kept only while the tool is in use. Revoking the app's access in TikTok account settings invalidates them immediately. Deleting the local configuration file removes them from the computer.

7. Contact

Questions about this policy can be sent to the e-mail address used to register this application with TikTok for Developers.
